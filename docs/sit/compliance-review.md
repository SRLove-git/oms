# 合规预评审（GSP / UDI / PCI-DSS）

> 预评审结论：代码与流程层面已具备主要控制点；生产环境类与外部资质类项为 M6 上线前置。

## GSP（医疗器械经营质量管理规范）

| 检查项 | 状态 | 说明 |
| :--- | :--- | :--- |
| 经营资质与商品资质绑定 | ✅ 已实现 | 商户入驻资质审核、商品注册证/经营许可证关联、资质过期禁止销售 |
| 质量追溯（批号/效期/序列号） | ✅ 已实现 | SKU/批次/序列号字段、FEFO 出库、效期预警 |
| UDI 关联与追溯 | 🟡 部分 | UDI 字段已建模并可查询；扫码出入库与全链路追溯报告待二期增强 |
| 温控/运输等专项（按品类） | 🟡 待评估 | 需按实际经营品类确认是否纳入 |

| 检查项 | 状态 | 说明 |
| :--- | :--- | :--- |
| 敏感信息不落库/最小化 | ✅ 已实现 | 卡号等 PAN 不在支付流水存储，渠道交易号代替 |
